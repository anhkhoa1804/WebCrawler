## Quick Start

This is a PHP-based web crawler. For the GitHub Pages demo:

1. Clone this repository
2. Set up a local PHP server (XAMPP, WAMP, or MAMP)
3. Navigate to `http://localhost/WebCrawler/`

## Features

✨ **Smart Crawling** - Multi-format file detection (PDF, images, videos, audio, code, archives)  
🎨 **Modern UI** - Minimal design with 85% opacity theater mode  
🔍 **Dynamic Search** - Real-time filtering across all files  
📦 **Bulk Download** - Download multiple files as ZIP  
👁️ **File Preview** - Built-in viewer for multiple formats
